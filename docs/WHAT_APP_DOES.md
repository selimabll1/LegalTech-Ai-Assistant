# What the app does / does not do

| The application does | The application does not do |
|---|---|
| Extract PDFs from the manual folder in MVP | Automatically connect to email in MVP |
| Read selectable PDF text | Guarantee perfect extraction for poor scans |
| Apply OCR with Tesseract when needed | Replace legal or business experts |
| Analyze text with a local Ollama LLM | Send documents to a cloud AI API |
| Return structured JSON analysis | Give definitive legal opinions |
| Score risk and opportunity | Make final business decisions |
| Export Excel for review | Remove need for human validation |
| Import corrected Excel | Retrain the LLM weights automatically |
| Build feedback memory | Guarantee zero errors |
