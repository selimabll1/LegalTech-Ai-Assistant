# System Requirements Notes

## Python
Python 3.11+ recommended.

## Ollama
Install Ollama locally and pull a model:

```bash
ollama pull qwen3:8b
```

## Tesseract OCR
Install Tesseract OCR locally and ensure the executable is in PATH.
Install French language data if available.

## Poppler
`pdf2image` needs Poppler for scanned PDF conversion.
Install Poppler and ensure its `bin` folder is in PATH on Windows.
